# 路书 Waymark｜产品计划书

这是一个可编辑的产品计划书，包含手机 App 功能框架草图，聚焦“有依据、可逐日审核、能联动路线和住宿”的自驾旅行规划产品。

## 打开与编辑

直接在浏览器打开 `index.html`。点击右上角“编辑内容”，再点击正文里的文字即可修改；离开页面前会自动保存到当前浏览器的本地存储。不同浏览器或设备之间不会自动同步。

- **导出 Markdown**：下载一份可在编辑器里继续修改的 `.md` 文件。
- **打印 / PDF**：使用浏览器打印功能导出 PDF。
- **恢复原稿**：清除当前浏览器保存的修改并恢复初始内容。

## 重要说明

“路书 / Waymark”为工作名；产品以手机 App 为主；首发区域、收费方式和指标目标均是待讨论/验证的假设。社交平台内容的批量接入不能作为首版依赖，需以官方授权、API 或合作范围为准。计划书网页本身为单机编辑稿，尚未连接云端协作或 GitHub 自动同步。
