# 路书 Waymark｜产品计划书

App 优先的产品计划书，包含信息架构、关键页面布局、核心流程与状态、最终行程交付形式和首版数据来源可行性。

## 打开与编辑

浏览器打开 `index.html`。点“编辑内容”后点击文字即可修改；修改保存在当前浏览器，不会自动更新公开网页。可导出 Markdown 或打印为 PDF。

## 章节

1. 产品概览
2. 用户问题
3. 核心流程与功能
4. App 信息架构
5. 核心页面布局
6. 核心流程与状态
7. 用户最终拿到什么
8. 数据来源与可行性
9. MVP 范围与关键依赖
10. 验证计划与下一步

## 数据边界

首版可从用户提供/上传的资料及美国国家公园、天气等公开信息开始；路线 API 需评估计费与展示许可；社交平台批量内容和实时住宿库存需授权或合作，不作为首版前提。
